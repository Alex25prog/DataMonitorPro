# DataMonitor Pro

**DataMonitor Pro** — приложение для мониторинга и анализа данных в реальном времени. Изначально задумывалось как универсальный монитор произвольных данных (TCP/WebSocket-сервер, таблица, экспорт), но выросло в многофункциональную платформу с отдельным блоком для мониторинга и анализа криптовалютных бирж.

Этот README фиксирует состояние проекта **до** предстоящего рефакторинга, в котором часть общего функционала (погода) планируется убрать в пользу более узкой фокусировки на бирже — сохранён «как есть» для истории и для тех, кому нужна именно эта, полнофункциональная версия.

---

## Возможности

### Биржа и криптомониторинг
- **Мультибиржевая архитектура** — Binance и Bybit одновременно, переключение активной биржи для графика в один клик
- **Свечной график в реальном времени** — загрузка истории (REST) + live-обновление через WebSocket
- **Выбор торговой пары** — BTCUSDT, ETHUSDT, SOLUSDT, XRPUSDT, ADAUSDT, DOGEUSDT, AVAXUSDT, DOTUSDT из списка
- **Быстрый тикер цены** — отдельный, более частый поток отдельных сделок (не раз в секунду, как свечи), с точностью отображения, автоматически подстраивающейся под масштаб цены (2 знака для BTC, до 6 — для дешёвых монет вроде DOGE)
- **Треугольный арбитраж** — независимый мониторинг связки BTC/ETH/USDT на Binance и на Bybit параллельно:
  - Раздельный расчёт Gross (чистое движение цены) и Net (с учётом комиссии)
  - Учитывается направление bid/ask на каждой ноге цикла (не last price)
  - История реально исполнимых возможностей — этап START → UPDATE PEAK → END, с длительностью, пиковым значением и пометкой, было ли завершение естественным или принудительным (Stop/обрыв связи)
  - Настраиваемая комиссия (тестовое поле ввода)

### Мониторинг данных (базовый функционал)
- **Приём данных** — TCP/WebSocket-сервер для приёма данных в формате JSON
- **Погода** — автоматический сбор температуры, давления, влажности (каждые 10 минут) через OpenWeatherMap
- **Визуализация** — график реального времени и таблица с данными
- **Сохранение истории** — все данные сохраняются в PostgreSQL
- **Фильтрация** — по типу данных и временному диапазону
- **Статистика** — расчёт минимума, максимума, среднего
- **Экспорт** — сохранение данных в CSV и PDF
- **Мультиязычный интерфейс** — переключение EN/RU

## Установка и сборка из исходников

### Требования

- Qt 6.8.3 или совместимая версия (компонент **MSVC 2022 64-bit** — проект использует MSVC, не MinGW)
- CMake 3.20 или выше
- Локально запущенный PostgreSQL-сервер (для полной функциональности — история данных и арбитража, экспорт; без него приложение всё равно запускается, но сохранение в БД будет недоступно)
- Git (опционально)

### Сборка проекта

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/DataMonitorPro.git
cd DataMonitorPro

# Конфигурация CMake (out-of-source build)
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release

# Компиляция
cmake --build build --config Release
```

Либо через Qt Creator: открыть `CMakeLists.txt`, выбрать Kit (Desktop Qt 6.8.3 MSVC2022 64-bit), переключить конфигурацию сборки на **Release** (Projects → Build Settings → Add → Release), собрать.

### Секреты (обязательно для полной функциональности)

Приложение ожидает файлы с ключом OpenWeatherMap API и паролем PostgreSQL в `.secrets/` в корне проекта:

```
.secrets/weather_api.key
.secrets/db_password.key
```

Без них погода и подключение к БД не заработают (остальной функционал — графики, realtime, треугольный арбитраж — не зависит от этих файлов и работает без них).

## Готовая сборка (Windows, без установки Qt Creator)

Собранная версия (`.exe` + все необходимые библиотеки) публикуется в разделе **[Releases](../../releases)** — скачать архив, распаковать, запустить, установка не требуется.

**Если при запуске не хватает DLL** (`VCRUNTIME140.dll` и подобные) — установите [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe) (также приложен в Release).

**Для сохранения истории данных и арбитражных возможностей** нужен локально запущенный PostgreSQL — без него приложение всё равно откроется и биржевой функционал будет работать, но история не будет сохраняться.

## Тестирование (генерик-мониторинг данных)

### Локальная отправка данных (на том же компьютере)
1. Запустите DataMonitor Pro, нажмите **Start Server**
2. Откройте в браузере файл `tools/websocket_sender.html`
3. Нажмите **Connect**, затем **Отправить**
4. Данные появятся в таблице приложения

### Удалённая отправка данных (с другого компьютера)
1. На сервере запустите DataMonitor Pro, нажмите **Start Server**
2. Узнайте IP-адрес сервера командой `ipconfig`
3. На другом компьютере откройте `tools/websocket_client.html`
4. Введите IP-адрес сервера, нажмите **Connect**
5. Отправляйте данные — они появятся на сервере

В папке `docs/screenshots` — скриншоты рабочей области отправки данных.

## Использование (биржа и арбитраж)

1. Выберите биржу (Binance/Bybit) и торговую пару из списков
2. **Load** — загрузить историю свечей; **Start Realtime** — подключить live-обновление и быстрый тикер цены
3. Панель **Triangular Arbitrage** запускается независимо для каждой биржи (кнопка Start у каждой строки) и не привязана к выбору пары/биржи для графика — обе биржи можно мониторить одновременно
4. История реально исполнимых арбитражных возможностей сохраняется в таблицу `arbitrage_opportunity_episodes` в PostgreSQL
